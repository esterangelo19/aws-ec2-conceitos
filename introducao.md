# Introdução ao Amazon EC2

O Amazon Elastic Compute Cloud (EC2) é o serviço da AWS que oferece capacidade de computação sob demanda.  
Com o EC2, é possível lançar instâncias (máquinas virtuais) em minutos e pagar apenas pelo tempo de uso.

Principais benefícios:
- Escalabilidade
- Flexibilidade de configuração
- Custo sob demanda
- Integração com outros serviços AWS
