# Criar uma Instância EC2

1. Acesse o console da AWS e vá até **EC2**.  
2. Clique em **Launch Instance**.  
3. Escolha uma **AMI** (por exemplo, Amazon Linux 2).  
4. Selecione o **tipo de instância** (ex: t2.micro).  
5. Crie ou selecione um **Key Pair**.  
6. Configure **Security Groups**.  
7. Clique em **Launch**.
