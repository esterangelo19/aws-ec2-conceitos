# Configurações Básicas de uma Instância EC2

1. **Escolha da AMI (Amazon Machine Image)**  
   Define o sistema operacional da instância (ex: Amazon Linux, Ubuntu, Windows Server).

2. **Tipo de Instância**  
   Determina os recursos de CPU, memória e rede.

3. **Par de Chaves (Key Pair)**  
   Usado para conectar-se à instância via SSH.

4. **Security Groups**  
   Controlam o tráfego de entrada e saída.

5. **Armazenamento (EBS)**  
   Discos anexados à instância para armazenamento de dados.
