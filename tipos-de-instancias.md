# Tipos de Instâncias EC2

As instâncias EC2 são classificadas por famílias, de acordo com o tipo de uso:

| Família | Finalidade | Exemplo |
|----------|-------------|----------|
| **General Purpose** | Equilíbrio entre CPU e memória | t3, m5 |
| **Compute Optimized** | Alta performance de CPU | c5, c6i |
| **Memory Optimized** | Processos que exigem muita RAM | r5, x2idn |
| **Storage Optimized** | Leitura e gravação intensiva em disco | i3, d2 |
| **Accelerated Computing** | GPUs ou FPGAs para tarefas gráficas | p3, g4 |
